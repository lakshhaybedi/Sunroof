# Changelog

## 0.1.0

First release.

- **Shelf** — a full-width strip that slides down from the top of the screen: scroll down, hold a modifier or pause at the top edge, drag a file up, or press a hotkey. Resizable height and columns, remembered per display. Liquid Glass or solid, light/dark/auto.
- **Clipboard** — history (10/25/50) with source app icons, text / rich text / URLs / images / files / colours, favourites that sync, search, pause, ⏎ to paste into the app you were in, ⌥⏎ plain text, ⌘1–9, concealed password-manager clips that never touch disk.
- **Files** — a drop-zone drawer: move / ⌥ copy / ⌘⌥ alias, browser images and links, icons or list, folders inside the panel, Quick Look, rename, search, auto-cleanup to the Trash, screenshot catcher.
- **Notes** — plain `.md` files with live markdown styling: checklists you click, auto-numbered lists, headings, highlights, code, links, images, `||concealed||` text; pins, search, conflict-safe sync.
- **Everywhere** — Send to Note from the clipboard, ⌘⇧F search across all three panels, floating sticky notes, Sparkle updates.
