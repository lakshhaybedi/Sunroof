# ShelfScroll Release Pipeline Implementation Plan (6 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything needed to ship ShelfScroll as a signed, notarized `.dmg` on GitHub Releases with Sparkle auto-updates — runnable locally unsigned today, and fully automated once the owner adds an Apple Developer ID and secrets.

**Architecture:** Sparkle 2 (`SPUStandardUpdaterController`) with an appcast on GitHub Pages; shell scripts for the icon, `.dmg` and performance measurement that work locally and in CI; a tag-triggered GitHub Actions workflow that signs, notarizes, staples, packages, signs the update and publishes.

**Tech Stack:** Sparkle 2 (SPM), `hdiutil`, `codesign`, `xcrun notarytool`/`stapler`, GitHub Actions (`macos-26`), Swift script for the icon.

**Spec:** `docs/superpowers/specs/2026-10-11-shelfscroll-design.md` (§2, §8, §10)

## Global Constraints

- Prior plans' Global Constraints apply. Sparkle is the only new dependency (spec §2).
- Feed URL: `https://lakshhaybedi.github.io/ShelfScroll/appcast.xml`. Public EdDSA key comes from the build setting `SPARKLE_PUBLIC_KEY` (empty until the owner generates one; Sparkle then refuses to install updates rather than installing unsigned ones).
- Secrets (names exact): `DEVELOPER_ID_P12`, `DEVELOPER_ID_P12_PASSWORD`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8`, `SPARKLE_ED_PRIVATE_KEY`.
- Nothing in this plan pushes, creates a GitHub repo, touches the keychain, or generates signing keys — those are owner steps documented in `RELEASING.md`.
- `.dmg` name: `ShelfScroll-<version>.dmg`; volume name `ShelfScroll`; contents: the app + `Applications` symlink.

## Review Focus

1. **Release workflow without secrets** (forks, or before the owner sets them up). Expect: build + tests run; signing/notarizing steps are skipped with a clear message, not a red failure mid-way. → Task 4.
2. **Sparkle without a public key.** Expect: app launches; "Check for Updates…" works and reports errors in Sparkle's own UI; no crash. → Task 1.
3. **Version mismatch** between tag and `MARKETING_VERSION`. Expect: the workflow fails early with a clear message. → Task 4.
4. **`.dmg` script run twice / leftover mounted volume.** Expect: idempotent; stale temp files cleaned. → Task 3.
5. **Perf script on a machine where the app is already running.** Expect: it quits the running instance first and measures a fresh one. → Task 3.

### Task 3: `.dmg` and performance scripts

**Files:** Create `scripts/make-dmg.sh`, `scripts/perf.sh`.

- `make-dmg.sh <path/to/ShelfScroll.app> <output-dir>`: reads the version from the app's Info.plist; stages app + `Applications` symlink in a fresh temp dir (removed on exit via `trap`); detaches any mounted `/Volumes/ShelfScroll*` first *(Review Focus 4)*; `hdiutil create -volname ShelfScroll -srcfolder <stage> -format UDZO -ov <out>/ShelfScroll-<version>.dmg`; prints the path.
- `perf.sh [path/to/ShelfScroll.app]` (default Release build): quits any running ShelfScroll *(Review Focus 5)*; launches with temp Files/Notes/Favorites folders and onboarding marked done (restores defaults afterwards); waits 60 s; prints memory (`footprint`), CPU, idle wake-ups, threads (`top`); then repeats with the shelf open (`openOnLaunch`); prints a Markdown table comparing against the §8 budget and exits non-zero if memory is over budget.

- [ ] **Step 3: Verify** `perf.sh` prints the table and exits 0.

### Task 4: Release workflow and docs

**Files:** Create `.github/workflows/release.yml`, `RELEASING.md`, `CHANGELOG.md`; Modify `README.md`, `.github/workflows/build.yml` (add Release build + `make-dmg.sh` smoke step, upload the unsigned `.dmg` as a workflow artifact).

`release.yml` (on `push: tags: ['v*']`, `runs-on: macos-26`, `permissions: contents: write`):
1. Checkout, `brew install xcodegen`, `xcodegen`, run tests.
2. Version check *(Review Focus 3)*: tag `vX.Y.Z` must equal `MARKETING_VERSION` in `project.yml`, else `::error::` and exit 1.
3. `if: secrets present` (env `HAS_SIGNING: ${{ secrets.DEVELOPER_ID_P12 != '' }}`): import the p12 into a temporary keychain; archive Release with `CODE_SIGN_IDENTITY="Developer ID Application"`, `CODE_SIGN_STYLE=Manual`, `OTHER_CODE_SIGN_FLAGS=--timestamp`; otherwise build unsigned and print `::warning::Signing secrets not set — publishing an unsigned build` *(Review Focus 1)*.
4. `scripts/make-dmg.sh`; if signing: `codesign` the dmg, `xcrun notarytool submit --wait` with the App Store Connect key, `xcrun stapler staple`.
5. If `SPARKLE_ED_PRIVATE_KEY` set: `sign_update` (from the Sparkle SPM checkout's `bin/`) → write `appcast.xml` entry (version, length, `sparkle:edSignature`, download URL to the Release asset, notes from `CHANGELOG.md`) and push to `gh-pages`.
6. `gh release create $TAG <dmg> --notes-file <changelog section>`.

`RELEASING.md`: one-time setup (Apple Developer Program; Developer ID Application certificate → export `.p12` → base64 → `DEVELOPER_ID_P12` + password; App Store Connect API key → `ASC_*`; `./bin/generate_keys` from Sparkle → private key → `SPARKLE_ED_PRIVATE_KEY`, public key → `SPARKLE_PUBLIC_KEY` in `project.yml`; enable GitHub Pages on `gh-pages`); per release (bump `MARKETING_VERSION`, add a `CHANGELOG.md` section, tag `vX.Y.Z`, push tag); local unsigned build instructions; Gatekeeper note for unsigned builds (right-click → Open).
`CHANGELOG.md`: `## 0.1.0` with the feature list. `README.md`: what it is, features, screenshots placeholder line removed (no fake images), install (Releases), build from source, permissions explained, privacy (nothing leaves the Mac), license.
