# Sunroof Widgets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A snap-grid widget band at the bottom of the shelf with Calendar (month view), Tasks (Reminders + Sunroof list), Music (Apple Music / Spotify), Weather (Open-Meteo) and System Stats.

**Architecture:** Layout is an ordered list of `(widget, size)` packed first-fit in reading order onto the grid (iOS-style): dragging reorders, resizing re-packs, nothing overlaps, items that don't fit stay in the list hidden. Each widget = an `@Observable` model with a pure, tested core + SwiftUI views; a `WidgetHost` starts all models on shelf show and stops them on hide.

**Tech Stack:** SwiftUI, EventKit, CoreLocation, IOKit power sources, Mach host statistics, NSAppleScript, URLSession (Open-Meteo), Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-12-widgets-design.md`

## Global Constraints

- Shelf closed → no widget timers, observers or network (budget: idle ~0 % CPU, 0 idle wake-ups, ≤ 80 MB closed / ≤ 150 MB open).
- Cell 150 pt square, 8 pt gaps; sizes small 1×1, medium 2×1, large 2×2. Each widget appears at most once.
- Default layout: Calendar L, Weather M, Music M, Tasks M, Stats S; default band rows = 2; band hideable.
- Permissions only when a widget needs them; usage strings in Info.plist; `com.apple.security.automation.apple-events` entitlement for signed builds.
- Sunroof tasks live in `<Notes folder>/Tasks.md` and are edited through `NoteStore` (so they're a normal note).

## Review Focus

1. **Shrinking the band / screen** (fewer columns or rows). Expect: reflow in order; items that don't fit are hidden, not dropped; they return when there's room. → Task 1 tests.
2. **Permissions denied** (calendar, reminders, location, Apple Events). Expect: a "Grant access" state with a button to the right System Settings pane; Tasks falls back to the Sunroof list; no crash. → checklist + code paths in Tasks 4–7.
3. **Network down / bad city** for Weather. Expect: last cached result with a "last updated" time, or a clear message. → Task 6 tests.
4. **Neither music app running.** Expect: "Not playing"; querying never launches Music or Spotify. → Task 7 test (merge) + code guard.
5. **Tasks.md edited elsewhere** (Notes panel, another Mac). Expect: widget reflects it; ticking never overwrites unrelated lines. → Task 5 tests.

### Task 1: Layout model

**Files:** Create `Sunroof/Widgets/WidgetKind.swift`, `Sunroof/Widgets/WidgetLayout.swift`; Test `SunroofTests/WidgetLayoutTests.swift`.

**Produces:**
```swift
enum WidgetSize: String, Codable, CaseIterable { case small, medium, large; var span: (w: Int, h: Int) }
enum WidgetKind: String, Codable, CaseIterable { case calendar, tasks, music, weather, stats
  var name: String; var symbol: String; var allowedSizes: [WidgetSize]; var defaultSize: WidgetSize }
struct WidgetItem: Codable, Equatable { var kind: WidgetKind; var size: WidgetSize }
struct WidgetPlacement: Equatable { let item: WidgetItem; let x: Int; let y: Int }
struct WidgetLayout: Codable, Equatable {
  var items: [WidgetItem]
  static let `default`: WidgetLayout          // calendar L, weather M, music M, tasks M, stats S
  func pack(columns: Int, rows: Int) -> (placed: [WidgetPlacement], hidden: [WidgetItem])  // first-fit, reading order
  mutating func move(_ kind: WidgetKind, toIndex: Int)
  mutating func resize(_ kind: WidgetKind, to: WidgetSize)   // ignores sizes not allowed
  mutating func add(_ kind: WidgetKind)        // appends at defaultSize; no duplicates
  mutating func remove(_ kind: WidgetKind)
  var available: [WidgetKind] { get }          // kinds not in items
}
// AppSettings: widgetRows: Int (2), showWidgets: Bool (true), widgetLayouts: [String: WidgetLayout] (JSON)
//              func widgetLayout(forDisplay:) -> WidgetLayout (default if none); setWidgetLayout(_:forDisplay:)
```
- [ ] Failing tests: default packing on 10×2 (calendar at 0,0; weather 2,0; music 4,0; tasks 6,0; stats 8,0); first-fit fills holes (L then S S S S on 3×2 → smalls at (2,0),(2,1)? and next row…); shrink to 4×2 hides the overflow in order and growing restores it *(RF1)*; move/resize/add/remove/no-duplicates; resize to a disallowed size is ignored; settings round-trip per display.
- [ ] Implement. Run `./test.sh WidgetLayoutTests`, then full suite. Commit `feat(widgets): layout model`.
