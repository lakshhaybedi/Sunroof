# ShelfScroll Shell Implementation Plan (1 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running menu-bar app whose full-width strip slides down from the top of the screen (scroll / hold / wait / drag / hotkey), holds three placeholder columns in resizable splits, resizes vertically, closes correctly, and has General / Panels / Appearance / Advanced settings plus first-run onboarding.

**Architecture:** AppKit shell (`NSPanel` + `NSSplitViewController`) hosting SwiftUI views. All trigger and geometry decisions live in pure value types with unit tests; thin AppKit adapters feed them events. Settings are one `@Observable` class backed by `UserDefaults`.

**Tech Stack:** Swift 6, SwiftUI + AppKit, macOS 26 deployment target, XcodeGen (`project.yml`, generated `.xcodeproj` not committed), Swift Testing, KeyboardShortcuts (SPM).

**Spec:** `docs/superpowers/specs/2026-10-11-shelfscroll-design.md` (§2, §3, §4, §8, §11)

## Global Constraints

- Deployment target macOS 26.0; Swift 6 language mode; `ARCHS = arm64 x86_64` for Release.
- Not sandboxed; hardened runtime ON; `LSUIElement = YES`.
- Bundle ID `com.lakshhaybedi.ShelfScroll`; product name `ShelfScroll`.
- Only SPM dependencies allowed in the whole app: Sparkle 2 (added in plan 6), KeyboardShortcuts (this plan).
- No SwiftData / Core Data. Settings in `UserDefaults`.
- No timers, animations, or event monitors running except those required by enabled triggers (§8 performance budget: idle CPU ~0 %, ≤ 2 wake-ups/s, ≤ 80 MB idle).
- Panel height: min 200 pt, max 85 % of the screen's `visibleFrame` height, persisted per display.
- Edge tolerance: cursor within 2 pt of a screen's top.
- Wait delays offered: 0.25 / 0.5 / 1 / 2 s. Hold modifiers offered: ⌘ ⌥ ⌃ ⇧.
- Defaults (match Unclutter): scroll ✓, hold ✗ (⌘), wait ✗ (0.5 s), show menu bar icon ✓, launch at login ✗, "Do not open window on launch" ✓, invert scroll ✗, theme Auto, material Liquid Glass, panel order Clipboard → Files → Notes, all enabled.
- Test command (used throughout): `xcodegen && xcodebuild test -project ShelfScroll.xcodeproj -scheme ShelfScroll -destination 'platform=macOS,arch=arm64' -quiet` (append `-only-testing:ShelfScrollTests/<Suite>` to narrow).

## Review Focus

1. **Stacked displays** — a display placed *above* part of another: the lower display's top edge where the upper display sits is not an edge (the cursor passes through). Expect: no trigger there; trigger on the upper display's top. → test in Task 3.
2. **Momentum scrolling** — inertial scroll events after the user lifts fingers. Expect: momentum never opens the panel, and momentum after a scroll-up close doesn't reopen it. → test in Task 3.
3. **⌘-drag of menu bar icons** with Hold = ⌘ — user holds ⌘ and drags a status item at the top edge. Expect: no open while a mouse button is down. → test in Task 3.
4. **Saved height larger than the current display allows** (display swapped, resolution changed, display disconnected). Expect: height clamped to 85 % of the new visible height. → test in Task 4.
5. **Auto-hidden menu bar / full-screen Space** — `visibleFrame.maxY == frame.maxY`. Expect: panel flush to the top of the screen, same width. → test in Task 4.

```swift
struct EdgeTriggerConfig: Equatable { var scroll: Bool; var hold: ModifierKey?; var wait: TimeInterval? }
enum EdgeInput {
  case moved(CGPoint, time: TimeInterval)
  case scroll(downAmount: CGFloat, isMomentum: Bool, at: CGPoint)   // positive = "pull down", already direction-normalized
  case modifiers(Set<ModifierKey>, at: CGPoint, mouseButtonDown: Bool)
  case drag(CGPoint)
  case tick(TimeInterval)
}
enum EdgeDecision: Equatable { case none, open(screen: Int), openFiles(screen: Int) }
struct EdgeTrigger {
  static let edgeTolerance: CGFloat = 2
  static let scrollThreshold: CGFloat = 6   // ponytail: calibration knob — tune on real trackpads/mice
  init(config: EdgeTriggerConfig, screens: [CGRect])    // Cocoa global coords (origin bottom-left)
  var screens: [CGRect]; var config: EdgeTriggerConfig
  private(set) var waitDeadline: TimeInterval?         // monitor schedules one `.tick` at this time
  func edgeScreen(at p: CGPoint) -> Int?
  mutating func handle(_ input: EdgeInput) -> EdgeDecision
  mutating func reset()                                 // call after open/close
}
```
Rules:
- `edgeScreen(at:)`: index of the screen whose `minX <= p.x < maxX` and `p.y >= maxY - edgeTolerance`, **unless** another screen contains `(p.x, maxY + 1)` (stacked displays) → `nil`.
- `.moved`: entering an edge with `config.wait` set → `waitDeadline = time + wait`; leaving the edge clears `waitDeadline` and the scroll accumulator.
- `.tick(t)`: if `waitDeadline` ≤ t and the last known point is still at an edge → `.open`.
- `.scroll`: ignored when `isMomentum` or `!config.scroll` or not at an edge; positive amounts accumulate, a negative amount resets the accumulator; accumulator ≥ `scrollThreshold` → `.open`, then reset.
- `.modifiers`: `config.hold` contained in the set, at an edge, and `!mouseButtonDown` → `.open`.
- `.drag(p)` at an edge → `.openFiles` (always enabled).
- `edgeConfig` on `AppSettings`: `scroll: scrollTrigger, hold: holdTrigger ? holdModifier : nil, wait: waitTrigger ? waitDelay : nil`.

```swift
enum ShelfGeometry {
  static let minHeight: CGFloat = 200
  static let maxFraction: CGFloat = 0.85
  static let defaultFraction: CGFloat = 0.5
  static let closeZone: CGFloat = 24          // pt above the panel's bottom edge
  static func clampHeight(_ h: CGFloat, visibleFrame: CGRect) -> CGFloat
  static func frame(height: CGFloat, screenFrame: CGRect, visibleFrame: CGRect) -> CGRect
  static func shouldCloseOnScroll(point: CGPoint, panelFrame: CGRect, upAmount: CGFloat) -> Bool
  static func displayKey(_ screen: NSScreen) -> String   // "display-<CGDirectDisplayID>"
}
final class ShelfPanel: NSPanel      // borderless + nonactivatingPanel; canBecomeKey true; canBecomeMain false;
                                     // collectionBehavior [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary];
                                     // level .statusBar; hidesOnDeactivate false; isReleasedWhenClosed false
@MainActor final class ShelfController {
  init(settings: AppSettings)
  var isVisible: Bool { get }
  var visibleFrame: CGRect? { get }
  func show(on screen: NSScreen, focus: PanelID?)
  func hide()
  func toggle(on screen: NSScreen)
  var onVisibilityChange: ((Bool) -> Void)?
}
```
- `frame`: x = `screenFrame.minX`, width = `screenFrame.width`, top = `visibleFrame.maxY`, height = clamped.
- `clampHeight`: `min(max(h, minHeight), visibleFrame.height * maxFraction)`.
- `shouldCloseOnScroll`: `upAmount >= EdgeTrigger.scrollThreshold && point.y <= panelFrame.minY + closeZone && panelFrame.contains(point)`.
- `ShelfController` content: a container view chosen by `settings.material` — `NSGlassEffectView` for `.glass`, a view filled with `NSColor.windowBackgroundColor` for `.solid` — holding the split view from Task 5 (use an empty `NSView` until then) and a bottom resize handle (8 pt SwiftUI `DragGesture` strip, `NSCursor.resizeUpDown` on hover) that updates the frame live and calls `setHeight` on drag end. `panel.appearance` from `theme` (`nil` / `.aqua` / `.darkAqua`).
- `show`: compute frame from saved height (default `visibleFrame.height * defaultFraction`), place frame offset above the screen top, `orderFrontRegardless()`, `makeKey()`, animate to final frame over 0.18 s (`NSAnimationContext`); with `NSWorkspace.shared.accessibilityDisplayShouldReduceMotion`, set final frame and animate `alphaValue` 0→1 instead.
- While visible only, install: global `leftMouseDown|rightMouseDown` monitor → `hide()`; local `keyDown` monitor for Esc (keyCode 53) → `hide()`; local `scrollWheel` monitor using `shouldCloseOnScroll` (upAmount = −downAmount normalized as in Task 6) → `hide()`. Remove all on `hide()`.
