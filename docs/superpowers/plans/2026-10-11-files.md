# ShelfScroll Files Implementation Plan (3 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Files placeholder with a working drop-zone drawer: icon/list views, arrange options, live folder updates, in-panel navigation, drop in (move / copy / alias, browser downloads), drag out, Quick Look, rename/trash, search, auto-cleanup, screenshot catcher, Files settings and an onboarding folder page.

**Architecture:** Pure helpers (`DrawerItem`, sorting, `FileDropOperation`, `uniqueDestination`, cleanup selection, screenshot detection) tested against temp folders; an `@Observable DrawerModel` that owns the current folder, a `FolderWatcher` (DispatchSource, no polling) and all file operations; a SwiftUI `FilesPanel`.

**Tech Stack:** Swift 6, SwiftUI + AppKit, QuickLookThumbnailing, Foundation `FileManager` / `URLResourceValues`, DispatchSource, `NSBackgroundActivityScheduler`, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-11-shelfscroll-design.md` (§6, §3, §8)

## Global Constraints

- Shell + Clipboard Global Constraints still apply.
- Default drawer folder `~/Documents/ShelfScroll Files`.
- Drop: plain = **Move**, ⌥ = **Copy**, ⌘⌥ = **Alias** (Finder alias via `URL.bookmarkData(options: .suitableForBookmarkFile)` + `URL.writeBookmarkData`).
- Name clashes get Finder-style suffixes: `name 2.ext`, `name 3.ext`, …; nothing is ever overwritten.
- Deletion is always to the Trash (`FileManager.trashItem`), never permanent.
- ⚙︎ menu copy: "New Folder", "Show in Finder", "Arrange By" (Name, Kind, Date Added, Date Modified), "Keep Folders on Top", "View As" (Icons ⌘1, List ⌘2), "Item Size" slider (4 stops = 48, 64, 96, 128 pt), "Auto-cleanup" (Off, After 7 Days, After 30 Days, After 90 Days), "Catch Screenshots".
- Defaults: Arrange By **Kind**, Keep Folders on Top **on**, View As **Icons**, Item Size stop 2 (64 pt), Auto-cleanup **Off**, Catch Screenshots **off**.
- Thumbnails via `QLThumbnailGenerator` at the item size, cached in `ThumbnailCache`; never decode full files.

## Review Focus

1. **Name clash** on drop, copy, rename, new folder or screenshot move. Expect a " 2"-style name, never an overwrite. → tests in Tasks 1, 2, 4.
2. **Dropping a file that is already in the current folder** onto the same folder. Expect a no-op (no duplicate, no deletion). → test in Task 2.
3. **Drawer folder missing** (deleted, renamed, cloud drive offline). Expect: the default folder is recreated silently; a custom folder shows "Folder not found" with "Choose…" — no crash. → test in Task 2.
4. **Auto-cleanup safety.** Expect: only top-level items, only when both "added" and "modified" are older than the cutoff, always to the Trash. → test in Task 4.
5. **Screenshot still being written** (macOS writes a hidden temp file, then renames). Expect: hidden/temporary files are skipped; only the final file moves. → test in Task 4.

### Task 1: DrawerItem, sorting, drop operations

**Files:** Create `Files/DrawerItem.swift`, `Files/FileDropOperation.swift`; Tests `DrawerItemTests.swift`, `DropOperationTests.swift`.

**Interfaces — Produces:**
```swift
enum ArrangeBy: String, CaseIterable { case name, kind, dateAdded, dateModified }
struct DrawerItem: Identifiable, Hashable {
  var id: URL { url }
  let url: URL; let name: String; let isDirectory: Bool; let kind: String
  let dateAdded: Date; let dateModified: Date; let size: Int64?
  static func load(_ url: URL) -> DrawerItem?     // resourceValues: isDirectory, isPackage (packages are files),
                                                  // localizedTypeDescription, addedToDirectoryDate, contentModificationDate, fileSize
}
func sortItems(_ items: [DrawerItem], by: ArrangeBy, foldersOnTop: Bool) -> [DrawerItem]
enum FileDropOperation: Equatable { case move, copy, alias
  static func from(_ flags: NSEvent.ModifierFlags) -> FileDropOperation }
func uniqueDestination(for name: String, in dir: URL) -> URL
@discardableResult func perform(_ op: FileDropOperation, _ source: URL, into dir: URL) throws -> URL
```
Sorting: `.name` ascending `localizedStandardCompare`; `.kind` by kind then name; `.dateAdded` / `.dateModified` newest first, ties by name. `foldersOnTop` puts directories first, each group sorted the same way. `perform`: if `source.deletingLastPathComponent() == dir` and op is `.move` → return `source` (no-op); otherwise destination = `uniqueDestination(source.lastPathComponent)`; move / copy / alias (bookmark file).

### Task 2: FolderWatcher + DrawerModel

**Files:** Create `Shared/FolderWatcher.swift`, `Files/DrawerModel.swift`; Tests `FolderWatcherTests.swift`, `DrawerModelTests.swift`.

**Interfaces — Consumes:** Task 1. **Produces:**
```swift
@MainActor final class FolderWatcher {
  init(url: URL, onChange: @escaping @MainActor () -> Void)   // DispatchSource .write/.rename/.delete on an O_EVTONLY fd,
                                                               // coalesced 0.2 s; cancel on deinit
}
@MainActor @Observable final class DrawerModel {
  init(root: URL, isDefaultRoot: Bool, trash: @escaping (URL) throws -> Void = { try FileManager.default.trashItem(at: $0, resultingItemURL: nil) })
  var root: URL                         // setting it navigates to the new root
  private(set) var current: URL
  private(set) var items: [DrawerItem]  // sorted with arrangeBy / foldersOnTop
  private(set) var rootMissing: Bool
  var arrangeBy: ArrangeBy; var foldersOnTop: Bool
  var query: String                      // non-empty → `items` are recursive name matches under root
  var breadcrumbs: [URL] { get }         // root … current
  private(set) var downloads: [UUID: Double]   // id → fraction 0…1
  func open(_ folder: URL); func goUp(); func reload()
  @discardableResult func newFolder() throws -> URL          // "untitled folder" (unique)
  func rename(_ item: DrawerItem, to name: String) throws -> URL   // unique if taken
  func trash(_ urls: [URL]) throws
  func drop(_ urls: [URL], operation: FileDropOperation) throws -> [URL]   // into `current`
  func download(_ remote: URL)                                         // URLSession → current, unique name
}
```
`reload` lists `current` with `contentsOfDirectory(…, options: .skipsHiddenFiles)`. If `root` doesn't exist: create it when `isDefaultRoot`, else set `rootMissing = true` and `items = []`. `query`: `FileManager.enumerator(at: root, options: [.skipsHiddenFiles, .skipsPackageDescendants])`, `localizedStandardContains` on the name, max 500 results. The watcher follows `current`.

### Task 4: Auto-cleanup + screenshot catcher

**Files:** Create `Files/Cleanup.swift`, `Files/ScreenshotCatcher.swift`; Tests `CleanupTests.swift`, `ScreenshotCatcherTests.swift`.

**Interfaces — Consumes:** `DrawerItem`, `uniqueDestination`, `FolderWatcher`, `Toast`. **Produces:**
```swift
enum Cleanup {
  static func itemsToClean(_ topLevel: [DrawerItem], olderThanDays days: Int, now: Date) -> [URL]
}
@MainActor final class CleanupScheduler {       // NSBackgroundActivityScheduler "com.lakshhaybedi.ShelfScroll.cleanup",
  init(settings: AppSettings, trash: …)          // interval 24 h, tolerance 1 h; runs once at start too;
  func start()                                   // trashes itemsToClean(root contents); Toast "Moved N old items to the Trash" if N > 0
}
enum ScreenshotCatcher {
  static func screenshotFolder() -> URL          // com.apple.screencapture "location" (tilde-expanded) or ~/Desktop
  static func isScreenshot(_ url: URL) -> Bool   // xattr com.apple.metadata:kMDItemIsScreenCapture present, not hidden
  static func collect(from source: URL, into drawer: URL, since: Date) -> [URL]   // moves into drawer/Screenshots (unique names)
}
@MainActor final class ScreenshotWatcher { init(settings: AppSettings); func start() }  // FolderWatcher on screenshotFolder()
                                                                                        // while settings.catchScreenshots
```
`itemsToClean`: an item qualifies only if `dateAdded < cutoff && dateModified < cutoff`; `days == 0` → `[]`. `collect` skips names starting with "." and files whose creation date is before `since`.
