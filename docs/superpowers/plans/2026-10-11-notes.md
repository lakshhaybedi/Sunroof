# ShelfScroll Notes Implementation Plan (4 of 6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Notes placeholder with a markdown notes panel: one `.md` file per note, live-styled editor (markers fade except on the caret line, clickable checkboxes, bullets, auto-numbered lists, headings, quotes, code, links, images, conceal), list view with pins and search, conflict-safe sync, Notes settings.

**Architecture:** Three pure, heavily tested layers — `MarkdownStyler` (one line → block kind + spans), `ListEditing` (text + selection → edited text + selection), `NoteStore` (files, titles, pins, conflicts) — under a thin AppKit editor (`NoteTextView`, an `NSTextView` that applies styler output as attributes and draws "decorations": checkboxes, bullets, rules, quote bars, conceal dots, images) and a SwiftUI `NotesPanel`. The text storage is always the exact markdown; styling never changes characters.

**Tech Stack:** Swift 6, AppKit `NSTextView` (TextKit 2), SwiftUI, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-11-shelfscroll-design.md` (§7, §3, §8). Floating stickies, Send to Note and ⌘K search are plan 5.

## Global Constraints

- Prior plans' Global Constraints apply.
- Default notes folder `~/Documents/ShelfScroll Notes`; images in `attachments/`; pins in `.pins.json` (array of filenames).
- First line is the title (leading `#`s and spaces stripped). New note filename `Untitled.md` (unique). On leaving a note, if the title changed, rename the file to `<sanitized title>.md` (unique; `/` and `:` → `-`; trimmed; max 100 chars; empty → `Untitled`).
- Save: atomic, ~1 s after typing stops, and on leaving a note / panel hide / app quit. Only notes with unsaved changes are written.
- Conflict: on an external change to a note with unsaved local edits, keep local text and write the disk version to `Title (conflict YYYY-MM-DD).md`. Never silently overwrite.
- Indent unit inserted by Tab: `"\t"`. Parsed indent level = tabs + (spaces / 2).
- Editor default font: system 14 pt; setting offers 12 / 13 / 14 / 16 / 18. Headings: H1 1.6×, H2 1.35×, H3 1.15×, bold. Markers on non-caret lines: `.tertiaryLabelColor` at 0.6× size.
- Header buttons: + (`plus`), ≡ (`list.bullet`), 🔍 (`magnifyingglass`), Aa (`textformat`).
- Shortcuts: ⌘B ⌘I ⌘U · ⌘⇧X strike · ⌘⇧H highlight · ⌘E code · ⌘K link · ⌘1/⌘2/⌘3 headings · ⌘⇧8 bullets · ⌘⇧7 numbers · ⌘⇧L checklist · ⌘⏎ toggle checkbox · ⌘⌥↑/↓ move line · Tab/⇧Tab indent · ⌘F find (system find bar).

## Review Focus

1. **External edit while typing** (other Mac syncs the same note mid-edit). Expect: local text kept, conflict copy written, nothing lost. → Task 3 test.
2. **Byte-exact round trip** (CRLF line endings, no trailing newline, emoji, unusual markdown). Expect: opening and leaving a note without editing never rewrites the file. → Task 3 test.
3. **Renaming collisions** (two notes titled "Ideas"; a title containing "/" or ":"). Expect: unique, valid filenames; pins follow renames. → Task 3 tests.
4. **Markdown that isn't markdown** (`2 * 3 * 4`, `snake_case_name`, `**unclosed`, a lone `` ` ``). Expect: no styling where there's no closed pair; never a crash on odd input. → Task 1 tests.
5. **Huge note** (10,000 lines, a 2 MB paste). Expect: typing stays responsive (only edited paragraphs restyled; fence changes restyle to the next fence). → Task 5 perf check.

### Task 1: MarkdownStyler

**Interfaces — Produces:**
```swift
enum BlockKind: Equatable {
  case paragraph, heading(Int), bullet(indent: Int), numbered(indent: Int, number: Int)
  case checklist(indent: Int, checked: Bool), quote, fence, code, rule, image(path: String)
}
enum SpanKind: Equatable { case marker, bold, italic, strike, underline, highlight, code, conceal, link(URL) }
struct MarkSpan: Equatable { var range: NSRange; var kind: SpanKind }   // UTF-16 offsets within the line
struct LineStyle: Equatable { var block: BlockKind; var spans: [MarkSpan] }
enum MarkdownStyler {
  static func parse(_ line: String, inCodeBlock: Bool) -> LineStyle
  static func isFence(_ line: String) -> Bool            // trimmed line starts with ```
}
```
Block rules (after leading indent): `#{1,3} ` heading (marker = `#…# `; 4+ `#` = paragraph); `- [ ] ` / `- [x] ` / `- [X] ` (also `*`) checklist; `- ` / `* ` bullet; `\d+\. ` numbered; `> ` quote; line == `---` rule; whole line `![…](path)` image; fence line; inside a code block every line is `.code` with no inline spans. Block marker ranges include the indent. Inline (outside code spans): `` `x` `` code (no nesting), `**x**`/`__x__` bold, `*x*`/`_x_` italic (opening not followed by space, closing not preceded by space; `_` only at word boundaries), `~~x~~`, `<u>x</u>`, `==x==`, `||x||` conceal, `[t](url)` link (markers `[` and `](url)`), bare `http(s)://…` link. Every delimiter is a `.marker` span; unclosed delimiters are plain text.

### Task 2: ListEditing

**Interfaces — Produces:**
```swift
struct TextEdit: Equatable { var text: String; var selection: NSRange }
enum BlockChange { case heading(Int), bullet, numbered, checklist, quote }
enum ListEditing {
  static func newline(_ t: TextEdit) -> TextEdit?                 // nil → let the text view insert a plain newline
  static func indent(_ t: TextEdit, outdent: Bool) -> TextEdit?   // nil when no selected line is a list item
  static func renumber(_ text: String) -> String
  static func toggleCheckbox(lineContaining location: Int, in text: String) -> String
  static func moveLine(_ t: TextEdit, up: Bool) -> TextEdit
  static func toggleInline(_ t: TextEdit, open: String, close: String) -> TextEdit
  static func toggleBlock(_ t: TextEdit, _ change: BlockChange) -> TextEdit
  static func expandShortcut(_ t: TextEdit) -> TextEdit?          // after typing a space: line "[] " → "- [ ] "
}
```
Rules: ⏎ in a list item continues it (`- `, next number, `- [ ] ` unchecked, same indent, `> ` for quotes), splitting at the caret; ⏎ on an item with no content removes the marker (ends the list) and inserts no newline; numbered continuation renumbers what follows. Tab/⇧Tab add/remove one `\t` (or 2 spaces) on every selected list line, then renumber. `renumber`: each run of consecutive numbered items at the same indent counts up from the run's first number; deeper-indented lines don't break the parent run; any other line ends all runs. `toggleInline`: wraps the selection and selects the inner text; if the selection is already wrapped by exactly `open`/`close`, unwraps; empty selection inserts `open+close` with the caret between. `toggleBlock` applies to every selected line; applying the same kind again removes it; heading replaces any existing heading/list prefix. `moveLine` swaps with the neighbouring line, keeps the caret's column, renumbers.

### Task 3: NoteStore

**Interfaces — Produces:**
```swift
struct Note: Identifiable, Equatable {
  var id: String { filename }
  var filename: String; var text: String; var modified: Date
  var title: String { NoteStore.title(of: text) }
  var preview: String { NoteStore.preview(of: text) }
}
@MainActor @Observable final class NoteStore {
  init(folder: URL, trash: @escaping (URL) throws -> Void = { try FileManager.default.trashItem(at: $0, resultingItemURL: nil) })
  var folder: URL                         // setting reloads
  private(set) var notes: [Note]          // pinned first (pin order), then modified desc
  private(set) var pinned: [String]
  func note(_ filename: String) -> Note?
  @discardableResult func create(text: String = "") -> Note
  func update(_ filename: String, text: String)        // memory + debounced save
  @discardableResult func finishEditing(_ filename: String) -> String   // flush + title rename; returns current filename
  func delete(_ filename: String) throws
  @discardableResult func duplicate(_ filename: String) -> Note
  func togglePin(_ filename: String)
  func search(_ query: String) -> [Note]   // title + text, localizedStandardContains
  func saveAll()                           // synchronous flush (quit)
  func syncFromDisk()                      // watcher callback; conflict rules
  func saveAttachment(_ png: Data, for filename: String) -> String   // "attachments/<base>-<n>.png"
  static func title(of text: String) -> String
  static func filename(forTitle title: String) -> String
  static func preview(of text: String) -> String    // lines 2–3, markers stripped, joined by space, max 140 chars
}
```
Loads `*.md` (non-recursive, skip hidden) with modification dates; remembers each note's on-disk mtime and a dirty flag. Unreadable or non-UTF-8 files are skipped (never rewritten). A `FolderWatcher` on the folder calls `syncFromDisk`.

### Task 5: NoteTextView (editor)

**Interfaces — Consumes:** `MarkdownStyler`, `ListEditing`. **Produces:**
```swift
enum Decoration: Equatable {
  case checkbox(range: NSRange, checked: Bool)   // the "[ ]" chars
  case bullet(range: NSRange, level: Int)        // the "-"/"*" char
  case rule(lineRange: NSRange), quoteBar(lineRange: NSRange)
  case conceal(range: NSRange), image(lineRange: NSRange, url: URL)
}
final class NoteTextView: NSTextView {
  convenience init(fontSize: CGFloat)            // TextKit 2, rich text off, allowsUndo, usesFindBar, spell checking on,
                                                 // automatic quote/dash substitution off
  var baseURL: URL?                              // notes folder, resolves image paths
  var onTextChange: ((String) -> Void)?
  private(set) var decorations: [Decoration]
  func restyle(paragraphsIn range: NSRange)      // re-parse affected lines (to next fence if a fence changed), set attributes
  func perform(_ edit: TextEdit)                 // replace via shouldChangeText/replaceCharacters/didChangeText (undoable)
  func toggleCheckbox(at location: Int)
  var revealedConceals: Set<Int>                 // conceal span starts revealed by click
}
```
Behaviour:
- `textStorage` delegate restyles edited paragraphs; selection changes restyle the old and new caret lines (marker visibility).
- Attributes per line from `LineStyle`: fonts (headings, code mono), colours (markers tertiary 0.6×, links accent + underline, highlight yellow 0.35 background, code background), strikethrough + secondary colour on checked checklist text and `~~` spans; markers on non-caret lines also get `.foregroundColor = .clear` when they are bullet/checkbox chars (drawn as decorations instead); image lines get `minimumLineHeight` = scaled image height and clear text when the caret is elsewhere.
- `draw(_:)`: after super, draw decorations at `firstRect`-style rects from `textLayoutManager.enumerateTextSegments` — ☐/☑ (SF Symbols `square` / `checkmark.square.fill`), • ◦ ▪ by level, a 1 pt rule, a 3 pt quote bar, `••••` over concealed text, images via `ThumbnailCache.thumbnail(for:maxPixelSize:)`.
- `mouseDown`: on a checkbox rect → `toggleCheckbox`; on a conceal → reveal; ⌘-click on a link → `NSWorkspace.open`; else super.
- Keys (`keyDown` / `doCommand(by:)`): ⏎ → `ListEditing.newline`; Tab/⇧Tab (`insertTab:`/`insertBacktab:`) → `indent`; space → `expandShortcut`; shortcuts from Global Constraints → `toggleInline` / `toggleBlock` / `moveLine`; ⌘⏎ → checkbox on caret line. Every transform goes through `perform` so it's one undo step.
- Paste/drop of image data → `NoteStore.saveAttachment` (via a closure) and insert `![](path)` on its own line.
